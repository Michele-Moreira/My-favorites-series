# My-favorites-series

My first project developed about the series that I like the most

## Frontend (React)

Este repositório agora contém uma aplicação React dentro da pasta `frontend`.

### Como iniciar

```bash
cd frontend
npm install      # instalar dependências
npm start        # iniciar servidor de desenvolvimento
```

O aplicativo de exemplo utiliza um componente `SeriesList` que faz um fetch em `/api/series` e demonstra tratamento de **loading** e **erro**.

> 🧩 Se não houver uma API real, podes adaptar o URL para um mock ou usar `json-server`.
